<p></p>
<p>REST Apis are included in this project.</p>
<p></p>
<p>The Structure of the project is the following:</p>
<ui>
<li>frontend: the Node.js project</li>
<li>backend: the maven project which generates the complete ROOT.war including both front and APIs</li>
